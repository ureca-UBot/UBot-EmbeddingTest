# 로컬 데이터와 생성물

Source: SK Telecom / KT / LG U+ public FAQ pages, used for non-commercial research/evaluation

FAQ 원문, 사용자 질문·정답·근거, 검수 화면, Excel·데이터 ZIP, 상세 로그와 캐시는 private/local 자료다. 로컬 파일은 실행 경로에 그대로 두고 Git 추적과 공개 대상에서 제외한다.

공개 범위와 실행 방법은 [데이터 관리 안내](DATA_POLICY.md), 공개 가능한 수치는 [집계 결과](public_results/README.md)를 따른다. 이전에 제공한 평가셋 ZIP은 비공개 보관용이며 공개 배포 대상이 아니다.

코드·환경 ZIP에는 본문이 없다. 공개 저장소만 clone한 경우 비공개 입력 없이 benchmark 전체를 재실행할 수 없으며, 별도 입력과 동결 manifest의 해시를 맞춰야 한다.
