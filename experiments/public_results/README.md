# 후속 실험 집계 결과

Source: SK Telecom / KT / LG U+ public FAQ pages, used for non-commercial research/evaluation

FAQ 질문·답변, 사용자 질문, 정답 행, 검색 문서 창을 포함하지 않은 공개 결과다.

- [결과 비교 보고서](comparison.md): 네 데이터셋의 구조별 지표와 부하 결과.
- [집계 검색 지표](aggregate_metrics.json): 4개 데이터셋×2개 엔진×13개 구조의 그룹별 문항 수, 문항 평균, 연결 그룹 평균. 문자열 본문은 포함하지 않는다.
- [HTTP 부하 수치](load_metrics.json): 동시 요청 수, 처리량, 지연 백분위, 실패 수 등 숫자 필드.
- [FAQ ID·출처 URL](faq_sources.json): 통신 3사 FAQ 2,535개에 대한 식별자와 원천 주소만 제공한다. LG U+ 등 일부 출처는 목록 페이지 주소다.

원본 측정값을 허용 필드로 추출했으며 지표를 다시 계산하거나 반올림해 저장하지 않았다. [평가 방법](../EVALUATION.md)과 [private/local 데이터 정책](../DATA_POLICY.md)을 함께 참고한다.
