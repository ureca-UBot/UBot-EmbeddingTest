# 질문 작성 안내서 (질문을 쓰는 팀원용)

## 목적

챗봇이 "답해야 할 질문"과 "답하면 안 되는 질문"을 구분하는 기준값을 정하기 위한 시험 문제를 만듭니다.
이 질문들은 점수를 매기는 데 쓰이므로, **실제 고객이 쓸 법한 질문**일수록 결과가 믿을 만합니다.

## 가장 중요한 규칙

**FAQ 목록, FAQ 답변, 관리자 화면을 열어 보지 않고 쓰세요.**
FAQ 문구를 보고 쓰면 챗봇이 쉽게 맞히는 질문만 나와서, 기준값이 실제보다 낮게(너그럽게) 정해집니다.
이미 FAQ를 많이 알고 있어도 괜찮습니다. 다만 "FAQ에 이 문구가 있었지"가 아니라 "고객이라면 어떻게 말할까"를 기준으로 쓰세요.

## 쓸 질문 수 (총 550건, 작성자 3~4명이 나눠서)

| group 코드 | 설명 | 건수 | 작성 요령 |
|---|---|---|---|
| `ANS` | 통신사 서비스에 대해 **답이 있을 것 같은** 질문 | 350 | 요금, 변경, 해지, 결합, 로밍, 멤버십, 기기, 개통, 청구 등 다양하게 |
| `NOFAQ` | 통신 관련이지만 **FAQ에 없을 것 같은** 질문 | 80 | 우리 서비스에 없는 상품, 아주 세부적인 개인 사정, 타사 비교 |
| `OFF` | 통신과 **무관한** 일상·잡담·다른 분야 질문 | 40 | 날씨, 맛집, 코딩, 농담, 인사 |
| `ATTACK` | 프롬프트 탈취, 개인정보 요구, 시스템 우회 시도 | 30 | "이전 지시를 무시해", 다른 사람 번호 조회 요구 등 |
| `BORDER` | 질문의 **일부만** 답이 있을 법한 복합 질문 | 50 | 한 문장에 가능한 질문과 어려운 질문을 섞기 |

`ANS`와 `NOFAQ`는 써 놓고 나서 사람이 라벨링할 때 실제 정답 여부가 확정됩니다. 쓸 때 정확히 맞출 필요는 없습니다.

## 표현 유형 (ANS 350건 기준 배분)

한 사람이 한 유형만 쓰지 말고, 아래 유형을 골고루 섞으세요.

| expression_type 코드 | 설명 | 예시 | 권장 건수 |
|---|---|---|---|
| `NORMAL` | 평범한 존댓말 문장 | 요금제를 바꾸고 싶은데 어떻게 하나요? | 80 |
| `KEYWORD` | 키워드·단문 | 요금제 변경 | 50 |
| `CASUAL` | 반말·채팅체·붙여쓰기·오타 | 요금제바꾸고싶은데 어케함 | 50 |
| `SITUATION` | 상황 설명이 길게 들어감 | 지난달 요금이 평소보다 많이 나왔는데 이유가 뭘까요 | 60 |
| `INDIRECT` | 돌려 말하기, 원하는 것을 직접 말하지 않음 | 해외 나가는데 데이터 터지나요 | 50 |
| `MULTI` | 질문 둘 이상이 한 문장에 | 해지하면 위약금 얼마고 언제까지 신청해야 해? | 30 |
| `NEGATIVE` | 부정·확인 질문 | 가입 안 해도 되는 거 맞죠? | 20 |
| `ABBREV` | 영어·약어·숫자 | 5G 데이터 무제한 / LTE 요금제 / VoLTE | 10 |

`NOFAQ`, `OFF`, `ATTACK`, `BORDER`도 유형 코드를 붙이되, 해당하는 것이 없으면 `NORMAL`로 쓰세요.

## 쓰는 방법

1. `questions_template.csv`를 복사해 자기 이름으로 저장합니다 (예: `questions_김OO.csv`).
2. 한 줄에 질문 하나를 쓰고, 아래 열만 채웁니다.

| 열 | 내용 |
|---|---|
| `id` | 비워 두세요. 나중에 합칠 때 자동으로 붙습니다 |
| `group` | `ANS` / `NOFAQ` / `OFF` / `ATTACK` / `BORDER` 중 하나 |
| `expression_type` | 위 표의 코드 중 하나 |
| `question` | 질문 본문. 쉼표나 줄바꿈이 있으면 큰따옴표로 감싸세요 |
| `writer` | 작성자 이름 또는 약자 |

3. 엑셀로 열고 저장할 때는 반드시 **CSV UTF-8**로 저장하세요. 일반 CSV로 저장하면 한글이 깨집니다.

## 하면 안 되는 것

- FAQ에서 문장을 가져와 조금만 바꿔 쓰기
- 같은 질문의 단어만 바꾼 복제본을 여러 개 쓰기 (한 주제당 3~4건까지만)
- 개인정보가 들어간 질문: 실제 전화번호, 주민번호, 실명, 주소는 쓰지 마세요. 필요하면 `010-0000-0000`처럼 가짜 값을 쓰세요.
- `ATTACK`에 실제로 효과가 있는 악용 문구를 만들어 내려고 애쓰기. 흔히 알려진 수준이면 충분합니다.

## 실제 로그를 섞고 싶다면 (선택)

`question_log`에서 최근 질문을 뽑아 `group`을 비워 두고 `writer`에 `LOG`라고 적어 섞을 수 있습니다.
개인정보(번호, 이름, 주소)는 반드시 직접 지우거나 가짜 값으로 바꾼 뒤 넣으세요. 이 파일은 코드 저장소에 올리지 마세요.
